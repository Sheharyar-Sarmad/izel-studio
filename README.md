## 🌟 Overview

**IzelStudio.Store** is a budget-friendly e-commerce web application built with the MERN stack (MongoDB, Express.js, React, Node.js). It provides complete CRUD operations for product management, shopping cart functionality, order processing, and an admin dashboard.

---

## ✨ Features

### 🔧 Admin Features
- Product CRUD (Create, Read, Update, Delete)
- Category management
- Order management & status updates
- User management
- Dashboard with analytics

### 🎨 Design
- Clean, responsive UI
- Mobile-first design
- Modern color scheme
- Smooth animations
